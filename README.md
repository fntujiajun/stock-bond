# 股债比价

沪深300全收益（H00300）÷ 中债-新综合财富指数，取 500 日滚动 z 值。
z 跌破 −1.5 为买入区，涨过 +1.0 为卖出区，中间不动。

不预测涨跌，只测量贵贱。

## 在线看

启用 GitHub Pages 后：`https://<你的用户名>.github.io/<仓库名>/`

## 页面

单文件，151 KB，**数据全部内嵌**——打开时零网络请求，断网也能看，接口挂了也不影响。

- 大数字：当前 z 值与所处区间
- 仪表盘：−1.5 买 / +1.0 卖 三段刻度
- 走势图：1月–15年 / 全部，可缩放、十字光标双向读数
- 右侧：光标高度对应的沪深300点位与涨跌幅
- 支持系统深浅色（`prefers-color-scheme`）

## 自动更新

`.github/workflows/daily.yml` 每个工作日 **北京时间 16:40** 自动运行：

1. 抓中证与中债数据
2. 重算 z 值
3. 重写 `index.html`
4. 有变化才提交

也可以在 Actions 页面点 `Run workflow` 手动触发。

> 注意：数据源是日频指数，收盘后才有当天值。盘中打开看到的是上一交易日。

## 本地生成

```bash
python scripts/build.py            # 无条件重新抓取
python scripts/build.py --if-new   # 只有出现更新的交易日才生成（退出码 2 = 已是最新）
```

依赖：Python 3.8+，只用标准库。

## 文件

```
index.html                  生成产物（自带数据，勿手改）
scripts/build.py            生成器
scripts/fetch_data.py       数据抓取
.github/workflows/daily.yml 定时任务
```

## 数据来源

- 中证指数官网：`www.csindex.com.cn`
- 中国债券信息网：`yield.chinabond.com.cn`

两个都是公开接口，无需密钥。

## 已知边界

- 中证接口只允许自家域名跨域（`access-control-allow-origin` 写死），中债完全不给 CORS 头。
  所以**浏览器端无法直接抓取**，必须由服务端或定时任务代抓。
- z 值需要 500 个交易日预热，页面数据从 2007-01 起。
- 均值回归假设可能失效：利率趋势性下行会推高比价中枢，“回到均值”可能回到一个已经不存在的过去。
